## 🚀 How to Upload to GitHub

### Option 1 — Upload through GitHub

1. Create a new GitHub repository.
2. Open the repository.
3. Click **Add file → Upload files**.
4. Upload:
   - `index.html`
   - `style.css`
   - `README.md`
   - the `assets` folder containing `profile.png`
5. Click **Commit changes**.

### Option 2 — Git commands

```bash
git init
git add .
git commit -m "Create professional freelance portfolio"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## 🌐 Enable GitHub Pages

After uploading:

1. Open your repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Click **Save**.
6. GitHub will generate your website link.

Your website will normally be available at:

```text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```

Search for:

Open `style.css` and edit the variables near the top:

```css

  --navy: #073b56;
  --deep: #042b3e;
  --teal: #08aeb5;
  --cyan: #64e5df;
}
```
